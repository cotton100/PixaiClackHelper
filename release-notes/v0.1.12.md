# 0.1.12

- 조합 예약의 재료를 프리셋·캐릭터, 이미지 설정, 스타일·시드, 청크 선택으로 묶었습니다. 제목을 눌러 각각 접거나 펼칠 수 있습니다.
- 접힌 상태에도 선택한 이름, 이미지 비율·크기·장수·모드, 청크 개수와 합쳐지는 순서를 표시합니다. 스타일·시드는 저장값과 미저장 변경을 구분합니다.
- 접기 상태를 이 PC에서 기억하며, 접어도 선택이나 입력 중인 내용은 유지됩니다. 프리셋·캐릭터 검색과 청크 검색은 각각 독립적입니다.
- 기존 생성 방식·예약·라이브러리·백업 형식은 유지합니다. 데이터 형식 8 / DB 19로 변경 없습니다.
