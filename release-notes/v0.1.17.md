# PixaiClackHelper 0.1.17

저장 자료가 다른 곳에서 변경됐을 때, 오래된 화면으로 덮어쓰는 일을 막는 정식 업데이트입니다. 0.1.17-beta.3에서 확인한 수정을 정식판으로 제공합니다.

- 재료·설정·예약·초안을 저장하기 직전에 최신 자료인지 확인합니다. 충돌이 발견되면 새 저장과 생성을 멈추고 현재 입력을 보존합니다.
- 충돌 안내의 **최신 자료 다시 불러오기**로 직접 새 자료를 읽을 수 있습니다. 실패하면 원래 화면을 유지합니다. 미저장 입력은 먼저 복사해 두세요.
- 앱으로 돌아왔을 때와 생성 직전에도 자료 변경을 확인합니다. 충돌 중에도 진행 중 작업의 중지와 재료 백업은 가능합니다.
- 캡처와 흐름도를 넣은 [사용 설명서](https://github.com/cotton100/PixaiClackHelper/blob/main/GUIDE.md)를 추가했습니다. 설치부터 조합·씬 예약, 자동 저장, 선택 백업까지 안내합니다.

기존 설치 위치와 자료 형식은 유지합니다. 정식판과 개발판은 같은 앱·같은 자료를 사용하며, 이번 업데이트에 자료 초기화나 DB 형식 변경은 없습니다.

설정에서 **업데이트 확인**을 누른 뒤 0.1.17을 선택하세요. 처음 설치하는 경우 아래 Assets의 `PixaiClackHelper-0.1.17-setup.exe`를 받으시면 됩니다.

검증: beta.3에서 실제 2장 생성·저장·재시작과 기존 자료 보존을 확인했습니다. 외부 변경 충돌은 자동 검사로 검증했으며, 실제 별도 GUI 두 개를 이용한 충돌 주입은 미검증입니다.
