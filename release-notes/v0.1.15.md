# PixaiClackHelper 0.1.15

백업할 자료와 가져올 범위를 선택할 수 있습니다. 기존 정식판에서 앱 안의 **업데이트 확인 → 최신 버전으로 업데이트**로 설치할 수 있습니다.

- 설정의 앱용 백업에서 씬·청크·캐릭터·프리셋·공통문 등 종류별 체크박스로 선택합니다. 폴더와 필요한 연결 자료도 함께 담습니다.
- 가져올 때 **기존 자료에 추가** 또는 **선택한 항목만 교체**를 고릅니다. 적용 전 현재/결과 개수와 연결 자료를 확인할 수 있습니다. 생성·화면 설정은 따로 체크해야 바뀝니다.
- 추가 가져오기는 같은 이름도 별도 자료로 보존하며, 씬·캐릭터·프리셋의 연결과 기존 공통문을 유지합니다. 교체할 때 남겨 둔 예약과 등록된 작업의 생성 문구도 보존합니다.
- 폴더 청크를 쓰는 옛 예약의 교체와 이전 버전에서 저장된 큰 작업의 복원을 지원합니다.
- 큰 백업을 많은 작업으로 펼칠 때 문구와 옵션을 복제하기 전에 수량·용량을 검사합니다.
- 구 테스트 자료의 이미지 캐시 참조값을 합성 값으로 교체했습니다.

선택은 개별 카드가 아닌 **종류 단위**입니다. 새 선택 백업은 이 기능이 있는 앱에서 읽어 주세요. 기존 전체 백업은 계속 읽을 수 있고, 스크립트용 내보내기는 기존 전체 형식을 유지합니다.

일반 설정 JSON에는 API 키·이미지 파일·저장 폴더·등록된 대기 작업을 넣지 않습니다. 전체 DB 자동 백업에는 보호된 키 데이터가 포함될 수 있으므로 공유하지 마세요.

기존 정식판의 설치 위치·자료·설정을 유지합니다. 별도 Beta 앱의 자료를 자동으로 합치지는 않습니다. 이번 버전의 기능은 0.1.15-beta.1과 같으며, 한 앱에서 정식/개발 채널을 전환하는 변경은 아직 포함하지 않았습니다. 실제 개인 설치본 업그레이드·유료 생성은 배포 자동 검사에 포함하지 않았습니다.
