# 0.1.11

- 이미지 정보 화면: PNG·JPEG·WebP를 놓거나 골라 생성 기록을 로컬에서 읽습니다. PNG 텍스트/압축 텍스트·NovelAI alpha stealth, EXIF 설명·사용자 주석, XMP 설명을 지원합니다. 모든 생성기 형식을 해석하는 것은 아니며 미지원 정보는 원문으로 확인합니다.
- 출처별 문구·설정을 확인하고 선택한 정보만 새 조합으로 가져옵니다. 청크 또는 모델 프리셋으로 따로 저장할 수 있습니다. 자동 예약·생성은 하지 않으며 기존 재료와 예약은 유지합니다.
- PNG 내부 생성 요청 정보 기록 옵션(기본 꺼짐). 그림 픽셀과 기존 정보를 보존하고 요청 프롬프트·모델/LoRA·요청 시드를 기록합니다. 개별 결과 시드를 추측하지 않습니다. JPEG·WebP는 원본 그대로 저장합니다.
- 기록 옵션은 실행기에 처음 넣을 때 작업별로 고정되어 저장 재개 때 바뀌지 않습니다. 기존 작업에 소급 적용하지 않습니다. 개인 정보가 될 수 있는 프롬프트를 공유 이미지에도 포함하므로 필요할 때만 켜세요.
- PNG 요청 정보 삽입 실패 시 원본 그대로 저장하고 작업에 경고를 남깁니다. 완료·재시작 후에도 경고를 확인할 수 있으며, 이 때문에 생성·저장을 무한히 재시도하지 않습니다.
- 데이터 형식 8 / DB 19. 이전 백업은 읽으며, 기록 옵션이 유실될 수 있는 구버전으로의 되돌리기는 차단합니다.
