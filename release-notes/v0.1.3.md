# PixAIS 0.1.3

- 조합 예약의 프리셋·캐릭터 바로 아래에서 비율·크기·1/4장 배치·Lite/Standard/Pro/Ultra를 선택합니다.
- 배치 수·모드는 예약마다 저장되어 이후 설정을 바꿔도 기존 예약에 영향을 주지 않습니다. 스타일·시드 공통 옵션도 조합 예약에서 설정합니다.
- 청크·캐릭터 폴더는 처음에 접힌 상태입니다. 검색하면 일치하는 항목을 펼쳐 보여 줍니다.
- 캐릭터 프롬프트 폴더 생성·선택·이동·폴더를 유지한 복제, 앱/최신 스크립트 백업 호환을 추가했습니다.
- 이전 백업은 그대로 읽습니다. 새 폴더/예약 형식을 읽지 못하는 0.1.2 이하로 앱 내 버전을 내리는 것은 차단합니다. 이전 버전의 업데이트 호환 검사도 형식 변경을 차단하므로 이번에는 설치 파일로 직접 업데이트하세요.

설치 위치는 기존 PixAIS 폴더를 유지하세요. 공개 릴리스 게시와 실제 계정 유료 생성 검증은 별도입니다.
