# PixaiClackHelper 0.1.18

폴더 정리·선택 백업·대기열 필터를 추가하고 관련 화면을 정돈한 정식 업데이트입니다.

- **폴더 단위 작업**: 청크·캐릭터 폴더와 씬 그룹을 한 번에 선택하고, 선택한 항목을 손잡이로 끌어 다른 폴더로 옮길 수 있습니다. 폴더 이름 변경과 삭제를 제공하며, 폴더만 삭제하면 내용은 미분류에 남습니다. 추가 버튼 옆에 폴더 추가를 배치했습니다.
- **청크·씬 폴더 선택 백업**: 필요한 폴더만 내보내거나 가져옵니다. 추가 방식은 기존 자료를 유지하고, 교체 방식은 선택한 범위만 바꿉니다. 빈 폴더를 교체하면 그 폴더 안의 자료가 비워지므로 적용 직전 범위와 개수를 확인하세요. 연결에 필요한 재료는 함께 포함됩니다.
- **대기열 필터**: 날짜·캐릭터·씬·프리셋·이미지 비율로 찾습니다. 기본은 최근 7일이며 날짜 밖 미완료 작업도 표시합니다. 다른 조건은 미완료 작업에도 적용됩니다. 필터를 접어도 현재 조건과 표시 개수가 보입니다.
- **실행·삭제 범위 안내**: 시작·저장 재개는 필터와 관계없이 전체 대기 작업에 적용됩니다. 선택 삭제·완료 목록 비우기는 현재 표시 범위만 정리하며 이미지 파일은 지우지 않습니다.
- **화면 정돈**: 선택 모드, 씬 그룹 선택과 보기 필터, 백업의 추가/교체 범위를 더 분명하게 표시합니다. 낮은 창에서도 실행 확인창과 대기열을 스크롤해 볼 수 있습니다.
- **PNG 안내 보완**: 생성 요청 정보 기록을 꺼 두면 새 정보를 추가하지 않습니다. 원래 이미지 정보를 삭제하는 설정은 아닙니다.

기존 설정·자료·등록 작업을 유지하며, 설치 위치나 DB 형식을 바꾸지 않습니다. 새 폴더 선택 백업은 **0.1.18 이상**에서 불러와 주세요. 예전 앱·스크립트 백업도 가져올 수 있고, 스크립트용 내보내기는 기존 전체 백업 방식을 유지합니다.

기존 사용자는 **설정 → 업데이트 확인 → 최신 버전으로 업데이트**를 이용하세요. 처음 설치하는 경우 아래 Assets의 `PixaiClackHelper-0.1.18-setup.exe`를 받으세요. [그림 사용설명서](https://github.com/cotton100/PixaiClackHelper/blob/main/GUIDE.md)에도 새 기능을 반영했습니다.

검증: 자동 검사 467개·임시 DB 검사 25개 통과. 합성 화면에서 다중 드래그와 백업 파일 왕복·최종 추가 적용·폴더 삭제 후 내용 보존을 확인했습니다. 실제 개인 자료를 이용한 업그레이드와 이번 버전의 유료 생성은 별도 검증하지 않았습니다.
