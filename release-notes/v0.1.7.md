# PixaiClackHelper 0.1.7

- 설정 화면 상단에 **업데이트 확인**을 따로 배치했습니다. 현재보다 새로운 정식 설치본이 있을 때만 **최신 버전으로 업데이트**가 활성화됩니다. 최신 버전이거나 확인 전·조회 실패 상태에서는 설치 버튼을 비활성화하며, 업데이트 확인은 다시 할 수 있습니다.
- 라이브러리의 **캐릭터·청크 탭 왼쪽 목록 상단**에 **폴더 추가**를 배치했습니다. 누르면 같은 목록 안에서 폴더를 만들거나 순서를 조정할 수 있습니다. 오른쪽 영역은 공통문 편집에 사용합니다.
- 캐릭터·청크의 소속 폴더 선택과 새 폴더에 저장 칸은 이름 바로 아래로 옮겼습니다. 기존 폴더·재료·예약·설정 저장 형식은 바꾸지 않았습니다.

0.1.4~0.1.6 사용자는 **설정 → 최신 버전으로 업데이트**로 받으세요. 0.1.7부터는 먼저 **업데이트 확인**을 누릅니다. 편집 중인 재료는 업데이트 전에 저장해 주세요.

PixAI와 제휴하지 않은 비공식 도구입니다. NAIS3 기반 GPL-3.0 소프트웨어이며 해당 버전 소스와 라이선스를 함께 제공합니다.
