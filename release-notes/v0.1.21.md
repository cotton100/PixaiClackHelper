# PixaiClackHelper 0.1.21

프롬프트 입력칸에 **태그 자동완성**을 추가했습니다. NAIS3에서 상속한 내장 태그 320,017개를 PC 안에서 검색하며 인터넷·API 키·크레딧이 필요하지 않습니다.

- 공통문, 프리셋 공통 문구, 캐릭터·출연, 청크, 씬의 포지/네거 입력칸에서 영문 태그를 두 글자 이상 입력하면 후보가 뜹니다. 밑줄과 공백을 같은 방식으로 검색합니다.
- **↑↓**로 후보를 고르고 **Tab / Enter / 클릭**으로 넣습니다. **Esc**는 후보를 닫고 **Shift+Enter**는 줄을 바꿉니다. 후보가 없을 때는 평소처럼 입력할 수 있습니다.
- 후보에 일반·작가·캐릭터·작품 등의 종류와 내장 사전의 게시물 수를 표시합니다. 입력한 글자로 시작하는 태그를 먼저 보여 주며, 화면 아래에서는 후보를 위로 펼칩니다.
- 커서가 있는 태그만 완성하고 뒤쪽 문구와 기존 숫자 가중치를 보존합니다. 여러 태그를 한 괄호로 묶거나 중첩한 경우도 처리합니다. 한글 조합 중에는 자동완성 키가 개입하지 않습니다.
- 목록에 없는 문구도 직접 입력할 수 있습니다. 내장 사전은 PixAI 실시간 순위가 아니며, 모델별 태그 효과나 최신 태그 포함 여부를 보장하지 않습니다. LoRA 트리거는 모델 설명에서 확인해 입력하세요.

NAIS3의 저작자·GPL-3.0 안내와 내장 태그 파일을 보존합니다. 기존 앱과 같은 설치·자료 폴더를 사용하며 **설정·라이브러리·기존 예약을 이어 씁니다.** 데이터 형식 9, DB 형식 19는 변경하지 않았습니다.

앱의 **설정 → 업데이트 확인 → 최신 버전으로 업데이트**에서 받을 수 있습니다. 개발판 채널을 사용 중이라면 정식판 채널을 선택한 뒤 확인하세요.
