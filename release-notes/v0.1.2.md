# PixAIS 0.1.2

- 설정에서 공개 출시 버전을 확인하고 원하는 버전을 골라 내려받을 수 있습니다.
- 최신 정식 버전, 이전 버전, 선택형 시험판 표시를 지원합니다.
- 다운로드만으로는 설치하지 않습니다. 설치 확인 후 작업 공간 백업을 만들고 설치 프로그램을 엽니다.
- 생성·저장 중이거나 현재 자료와 호환되지 않는 버전은 설치를 막습니다.
- 0.1.1의 씬 직접 생성·그룹 표시·청크 폴더 목록·모델/LoRA 링크 가져오기를 포함합니다.

0.1.1 이하에서는 이 업데이트 기능이 없으므로 이번 버전은 설치 파일로 업데이트해야 합니다. 이후에는 앱의 설정 → 앱 업데이트·버전 선택에서 진행할 수 있습니다. 버전 선택은 업데이트 메타데이터가 함께 게시된 Windows x64 릴리스에 한합니다.

프리셋 전용 포지·네거는 아직 지원하지 않습니다. PixAI와 제휴하지 않은 비공식 초기 버전입니다.
