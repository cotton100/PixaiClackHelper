# PixaiClackHelper 0.1.17-beta.1

정식 0.1.16과 같은 기능 코드로, 같은 앱에서 개발판을 받는 흐름을 사용할 수 있는 첫 통합 개발판입니다.

- 기존 정식 앱은 먼저 0.1.16으로 업데이트한 다음, 설정에서 **개발판 (Beta)** → **업데이트 확인** → 표시된 개발판 버전으로 전환하세요.
- 두 채널은 설치 위치와 기존 자료·설정을 공유합니다. 채널 선택만으로 설치하지 않으며, 명시적으로 전환 버튼을 눌러야 검증·백업 후 설치합니다.
- 정식판을 고르면 호환되는 정식 버전으로 돌아갈 수 있습니다. 현재 자료를 읽지 못하는 버전은 차단합니다. 이번 두 버전은 같은 자료 형식과 DB 버전입니다.
- 이전 별도 Beta 설치와 자료는 자동으로 옮기지 않습니다. 이번 설치 파일에는 예전 `Beta-` 접두사가 없습니다.

일반 사용자는 정식판을 유지하면 됩니다. 이번 개발판은 버전 표기와 이 출시 안내 외에 정식 0.1.16과 기능 차이가 없습니다.
