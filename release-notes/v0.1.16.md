# PixaiClackHelper 0.1.16

정식판과 개발판을 **같은 앱·자료**로 전환할 수 있습니다.

- 기존 정식 앱에서 이번 0.1.16으로 업데이트한 다음, 설정에서 **개발판 (Beta)**을 고르고 표시된 버전으로 전환하세요. 프리셋·청크·설정과 기억한 API 키를 기존 자료 위치에서 이어 씁니다.
- 채널 선택은 선택값만 저장하며 설치를 시작하지 않습니다. 업데이트/전환 버튼을 누르면 다운로드·검증·백업 후 설치합니다.
- 정식판으로 돌아갈 때 낮은 버전이면 안내하고, 현재 자료를 읽지 못하는 버전은 설치하지 않습니다. 동일 채널에서 이미 최신이면 업데이트 확인만 가능합니다.
- 이전의 별도 Beta 설치 파일은 전환 대상에서 제외합니다. 옛 별도 Beta의 자료를 정식 앱으로 자동 복사하거나 합치지 않습니다. 필요한 자료는 선택 백업으로 옮겨 주세요.

일반 사용자는 정식판을 유지하면 됩니다. 개발판은 직접 선택한 사용자만 받습니다. 채널 전환은 원래 정식 앱의 설치 위치와 `%APPDATA%/PixAIS`를 사용하며, 기존 자료 형식/DB 버전은 바뀌지 않습니다.
