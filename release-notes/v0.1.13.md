# PixaiClackHelper 0.1.13

- 설정에서 정식판 / 개발판(Beta) 업데이트 종류를 선택하고 기억합니다. 같은 종류의 최신 버전은 기존처럼 백업 후 업데이트합니다.
- 개발판은 별도 앱으로 설치합니다. 정식판의 설정·프리셋·대기열·API 키를 자동으로 옮기거나 덮어쓰지 않습니다. 필요한 재료는 설정 백업으로 가져오세요.
- 다른 종류를 선택하면 별도 설치 파일을 브라우저에서 열어 직접 설치할 수 있습니다. 아직 게시된 파일이 없으면 설치 버튼이 비활성화됩니다.
- 최신 버전에서는 업데이트 버튼을 비활성화하고 업데이트 확인만 사용할 수 있습니다. 채널 변경 시 받아 둔 이전 설치 파일의 실행 준비도 해제합니다.
- 정식판의 기존 자료 위치와 저장 형식(8 / DB19)은 유지합니다.

이 앱은 PixAI와 제휴하지 않은 비공식 도구입니다. 실제 이미지 생성에는 본인의 공식 API 키와 크레딧이 필요합니다.
