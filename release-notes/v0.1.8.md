# PixaiClackHelper 0.1.8

- **이미지 비율을 눈으로 구분**할 수 있도록 비례 도형과 가로형·세로형·정사각형 표시를 추가했습니다. 조합 예약·씬·예약 목록·최근 조합·대기열에 적용됩니다.
- **씬 카드에 최근 생성 이미지 썸네일**을 표시합니다. 씬에서 새로 예약하거나 「조합으로 열기」에서 예약한 작업부터 연결됩니다. 씬 이름 변경·재시작·대기열 정리 후에도 유지하며, 복제한 씬은 새 결과부터 표시합니다. 기존 작업은 씬 연결 정보가 없어 소급 표시하지 않습니다.
- **씬의 캐릭터·저장 출연 목록에도 캐릭터 폴더**를 적용했습니다. 기본으로 접어 표시하고, 검색하면 일치하는 항목을 펼칩니다. 접기·검색·폴더 이동 후에도 선택과 예약 순서를 유지합니다.

썸네일은 원본을 변경하지 않는 이 PC의 미리보기 캐시입니다(최대 200개 씬·약 4MB). 썸네일 실패 때문에 생성 작업을 재제출하지 않습니다. 수동 설정 백업 파일에는 이미지를 넣지 않습니다.

기존 설정·라이브러리·예약을 유지합니다. 새 씬 연결 정보의 유실을 막기 위해 0.1.7 이하로 되돌리는 앱 내 설치는 차단합니다.

**설정 → 업데이트 확인 → 최신 버전으로 업데이트**로 받으세요. 편집 중인 재료는 먼저 저장해 주세요.

PixAI와 제휴하지 않은 비공식 도구입니다. NAIS3 기반 GPL-3.0 소프트웨어이며 해당 버전 소스와 라이선스를 함께 제공합니다.
