# PixaiClackHelper 0.1.10

- 청크·캐릭터·모델/LoRA 프리셋 목록에 태그 미리보기를 추가했습니다. 포지 최대 두 줄, 네거와 모델/LoRA 정보 한 줄을 표시하며 전체 내용은 마우스를 올려 확인할 수 있습니다.
- 라이브러리 → 공통문에서 이름을 붙인 포지·네거 세트를 여러 개 저장·복제·삭제할 수 있습니다.
- 모델/LoRA 프리셋에 공통문 세트를 연결할 수 있습니다. 연결한 세트가 기본 공통문을 대체하고, 연결이 없으면 기본 공통문을 사용합니다. 기존 프리셋 자체 문구는 함께 적용됩니다.
- 공통문 변경은 새 조합에 반영합니다. 이미 등록한 예약과 대기 작업에는 당시 문구를 보존합니다. 세트 삭제 시 연결된 프리셋은 기본 공통문을 쓰게 된다는 안내를 표시합니다.

기존 설정·백업을 읽을 수 있습니다. 앱용 백업에 공통문 세트와 연결을 보존하며, 스크립트용은 호환되지 않는 항목과 영향을 미리 안내합니다. 새 필드를 읽지 못하는 구버전으로의 되돌리기를 막기 위해 데이터 형식 7 / DB 19를 사용합니다.

PixAI와 제휴하지 않은 비공식 도구입니다. NAIS3 기반 GPL-3.0 소프트웨어입니다.
