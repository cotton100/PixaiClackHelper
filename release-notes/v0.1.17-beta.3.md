# PixaiClackHelper 0.1.17-beta.3

다른 곳에서 저장 자료가 바뀐 뒤, 오래된 화면이 그 자료를 덮어쓰지 못하도록 보호합니다.

- 설정·재료·예약·초안을 저장하기 직전에 최신 DB와 비교하고, 달라졌다면 저장을 차단합니다. 연속으로 입력해 대기 중인 저장도 함께 중단합니다.
- 충돌 안내가 나타나면 화면의 입력을 유지합니다. 필요한 내용을 복사하거나 재료를 백업한 뒤 **최신 자료 다시 불러오기**를 선택하세요. 재료 백업에는 조합 초안·등록 작업·편집기의 미저장 입력이 포함되지 않습니다.
- 최신 자료 불러오기가 실패하면 기존 화면을 보존합니다. 확인 없이 자동으로 자료를 교체하지 않습니다.
- 앱에 다시 돌아왔을 때와 새 생성 직전에도 변경을 확인합니다. 충돌 중에는 새 생성과 편집을 막고, 진행 중 작업의 중지는 허용합니다.

기존 설치 위치·자료 형식·DB 버전은 유지합니다. 설정에서 개발판을 선택한 사용자에게 제공되는 시험판이며, 정식 최신 버전은 0.1.16입니다. 앞서 보고된 업데이트 직후 표시 불일치의 직접 원인을 확정한 수정은 아닙니다.
