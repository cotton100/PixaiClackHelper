# PixaiClackHelper 0.1.6

- 모델·LoRA 프리셋마다 **이 프리셋의 공통 포지 / 공통 네거**를 저장합니다. 그 프리셋을 고른 조합에는 전역 공통문 바로 뒤에 같은 블록으로 들어가며, 미리보기·단일 예약·여러 캐릭터×여러 씬 일괄 예약·등록 요청에 같은 문구가 적용됩니다. LoRA 트리거 위치(맨 앞·공통문 뒤·캐릭터 뒤·청크 뒤·맨 뒤)의 뜻과 번호는 그대로입니다.
- 프리셋 문구를 비워 두면 이전 버전과 같은 결과입니다. 이미 예약·등록한 작업의 사본은 이후 프리셋을 고쳐도 바뀌지 않으며, 재시작·백업 복원 뒤에도 같습니다. 예전 사본에 현재 프리셋 문구를 소급해 넣지 않습니다.
- 조합 화면의 순서 목록에서 공통 블록이 「공통문 + 프리셋 문구」로 표시되고, 포지·네거 미리보기에 실제 합쳐진 문구가 보입니다.
- 앱용 백업은 프리셋 문구와 예약 사본을 그대로 담습니다. 스크립트용 내보내기는 스크립트가 모르는 프리셋 문구를 빼며, 어떤 프리셋 문구가 빠지는지·문구가 든 예약 몇 개를 제외하는지·해당 프리셋을 쓰는 최근 조합/즐겨찾기 수를 내보내기 전에 보여 줍니다.
- 사본이 없는 옛 예약도 실제 적용할 프리셋 문구를 확인하여, 문구가 유실되는 예약은 스크립트용 백업에서 제외합니다. 앱의 원본 예약과 앱용 백업은 그대로 유지됩니다.
- 프리셋 문구를 모르는 0.1.5 이하로 앱 내 되돌리기를 막습니다(자료 형식 4). 기존 자료는 그대로 읽습니다. 기존 라이브러리·예약·대기열·출력 폴더·동시 작업 수·보호 저장한 키·조합 선택 상태를 유지합니다.

0.1.4 이상 사용자는 **설정 → 최신 버전으로 업데이트**를 사용하세요. 0.1.3 이하 사용자는 설치본으로 한 번 직접 설치해야 합니다.

편집기의 아직 ‘재료 저장’을 누르지 않은 프리셋 문구는 업데이트 전에 저장해 주세요. 유료 생성 승인 체크는 매 실행 확인합니다.
