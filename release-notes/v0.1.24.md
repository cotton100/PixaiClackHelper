# PixaiClackHelper 0.1.24

**같은 PC의 PixAI 유저스크립트와 라이브러리를 양방향으로 동기화할 수 있습니다.** 앱과 스크립트 모두 동기화 기능이 포함된 버전이 필요하며, 기본은 꺼짐입니다.

- **설정 → 같은 PC 라이브러리 동기화**에서 사용을 켜고 **새 연결 코드**를 만드세요. 같은 PC의 스크립트 설정에 코드를 넣어 연결한 뒤, 앱의 **동기화 미리보기 → 확인한 내용 적용**으로 첫 합치기를 확인합니다. 코드는 5분 동안 한 번만 사용할 수 있습니다.
- 공통문·모델/LoRA 프리셋·캐릭터·청크·씬·출연·저장한 일괄 구성과 폴더·순서·연결을 공유합니다. 같은 항목의 수정은 이어서 반영하며 이름만 같은 별도 항목을 임의로 합치지 않습니다.
- 첫 동기화 뒤에는 삭제도 반영합니다. 양쪽에서 같은 항목을 다르게 수정하거나 삭제와 수정이 겹치면 사용할 쪽을 선택할 때까지 기다립니다. 스크립트에서 자동 동기화를 켜면 앱과 탭이 열린 동안 약 10초 간격으로 확인하며, 첫 합치기와 충돌은 자동 적용하지 않습니다.
- 이미 만든 예약은 당시 문구를 유지합니다. 예약·실행 작업·최근 조합·즐겨찾기·생성/화면 설정·API 키·이미지 저장 폴더·이미지 파일은 각 도구에 따로 남습니다.
- 미저장 편집이나 생성 중에는 반영을 보류합니다. 저장 도중 응답이 끊겨도 완료가 확인되기 전 다음 동기화가 앞지르지 않으며, 다시 연결해 저장 확인을 이어갑니다.
- 연결은 이 PC 안에서만 열며 외부 동기화 서버를 사용하지 않습니다. 사용하지 않을 때는 앱에서 끄거나 연결을 해제할 수 있습니다. 연결정보는 일반 라이브러리 백업에 포함하지 않습니다.

기존 설치·자료 폴더와 작업 공간 형식은 유지합니다. 설정과 라이브러리, 기존 예약을 이어 쓰며 데이터 형식 10·DB 형식 19는 바뀌지 않습니다.

검증: 앱 자동 검사 665개·임시 DB 검사 26개, 실제 로컬 통신 검사 14개와 설치 패키지 실행 검사를 통과했습니다. 합성 라이브러리로 동기화 화면의 연결·첫 합치기·예약 보존·연결 해제를 확인했습니다. 독립 리뷰에서 발견한 지연 저장 경합을 수정하고 통신 중단·재시작·충돌 재시도를 재검증했습니다. 개인 자료나 유료 생성은 이 검사에 사용하지 않았습니다.
