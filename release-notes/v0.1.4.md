# PixaiClackHelper 0.1.4

- 앱 이름을 PixAIS에서 PixaiClackHelper로 변경했습니다. 기존 작업 공간·설정·라이브러리와 내부 앱 식별자는 유지합니다.

- 설정의 **최신 버전으로 업데이트** 버튼 한 번으로 최신 정식 버전 확인 → 다운로드 → 파일 검증 → 작업 공간 백업 → 설치·재시작을 진행합니다. Windows 권한 확인은 별도로 표시될 수 있습니다.
- **다른 버전 선택 · 변경 내용**을 펼치면 이전 버전과 시험판을 직접 고를 수 있습니다. 원클릭 업데이트는 시험판이나 이전 버전을 자동 선택하지 않습니다.
- 새 버전이 기존 자료를 읽을 수 있다고 명시한 경우 정상 업그레이드를 허용합니다. 현재 자료를 읽지 못하는 구버전은 계속 차단합니다.
- 생성 중이거나 미완료 저장 작업이 있으면 업데이트를 멈춥니다. 파일 검증·백업에 실패해도 설치하지 않습니다.
- 0.1.3의 예약별 배치·모드, 캐릭터 폴더와 0.1.2의 버전 선택 기능을 포함합니다.

0.1.3 이하의 업데이트 주소/동작은 이미 설치된 앱에 남아 있으므로, **이번 0.1.4는 설치 파일로 한 번 직접 업데이트**해 주세요. 이후 공개되는 정식 버전부터 앱 안의 버튼으로 업데이트할 수 있습니다. 기존 PixAIS 설치 경로를 유지하세요.

PixAI와 제휴하지 않은 비공식 도구입니다. NAIS3 기반 GPL-3.0 소프트웨어이며 해당 버전 소스와 라이선스를 함께 제공합니다.
