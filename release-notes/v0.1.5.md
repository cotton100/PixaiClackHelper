# PixaiClackHelper 0.1.5

- 조합 예약에서 선택한 프리셋·캐릭터·청크와 순서·LoRA 트리거 위치·횟수·이미지 옵션을 자동 저장하고 재시작 후 복원합니다. 이전 버전에서 메모리에만 남았던 선택 상태는 소급 복원할 수 없습니다.
- ‘이 PC에 키 기억하기’ 체크를 실제 보호 저장 상태와 맞춰 표시합니다. 저장을 선택하지 않은 API 키는 계속 이번 실행에서만 사용합니다.
- 설치 파일로 직접 업데이트한 경우도 새 버전 첫 실행 전에 기존 PixAIS 설정을 자동 백업합니다. 앱 내 업데이트는 설치 전에 백업합니다. 백업의 DB 무결성과 전체 설정 일치를 검사하며 실패하면 진행하지 않습니다.
- 자료 경로·라이브러리·예약·대기열·출력 폴더·동시 작업 수·보호 저장한 키를 유지합니다. 백업은 `%APPDATA%/PixAIS/version-backups`에 남습니다.
- 자동 저장한 조합 상태를 모르는 구버전으로 앱 내 되돌리기를 막습니다. 기존 자료는 그대로 읽을 수 있습니다.

0.1.4 사용자는 **설정 → 최신 버전으로 업데이트**를 사용하세요. 0.1.3 이하 사용자는 설치본으로 한 번 직접 설치해야 합니다. 기존 PixAIS 설치 경로를 유지하세요.

편집기의 아직 ‘저장’을 누르지 않은 프롬프트나 ‘현재 구성 저장’을 누르지 않은 씬 일괄 구성은 업데이트 전에 저장해 주세요. 유료 생성 승인 체크는 매 실행 확인합니다.

PixAI와 제휴하지 않은 비공식 도구입니다. NAIS3 기반 GPL-3.0 소프트웨어이며 해당 버전 소스와 라이선스를 함께 제공합니다.
