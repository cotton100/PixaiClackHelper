# PixaiClackHelper 0.1.23

**앱이 자체적으로 걸었던 LoRA 최대 5개 제한을 제거했습니다.** 프리셋과 캐릭터를 합쳐 6개 이상이어도 조합·씬 예약과 생성 요청을 진행할 수 있습니다. 다른 개수 제한으로 바꾸거나 목록을 잘라내지 않습니다.

- 이미지 생성 정보 읽기에서도 6개 이상 LoRA 목록이 누락되던 문제를 수정했습니다. PNG 기록·읽기·조합 가져오기에서 전체 목록을 보존합니다.
- LoRA 허용 개수는 서버 응답으로 확인합니다. 서버가 요청을 거절하거나 생성 실패를 보고하면 다음 작업 전송을 멈추고 오류와 남은 대기열을 보존합니다. 자동 재시도·재생성하지 않습니다.
- 기존 LoRA 버전 ID·수치·중복·설정 충돌 검사는 유지합니다. 이미 만든 예약의 사본, 저장된 설정과 라이브러리도 유지합니다.

검증: 자동 검사 604개·임시 DB 검사 26개, 실제 앱에서 7개 LoRA로 예약·재시작 복원, 12개 요청·PNG 정보 왕복을 확인했습니다. 서버 거절 후 정지는 합성 오류 응답으로 확인했으며 실제 유료 생성은 하지 않았습니다.

앱의 **설정 → 업데이트 확인 → 최신 버전으로 업데이트**에서 받을 수 있습니다. 설치·자료 경로와 데이터 형식은 0.1.22와 같습니다.
