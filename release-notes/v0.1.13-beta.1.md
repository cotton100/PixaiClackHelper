# PixaiClackHelper Beta 0.1.13-beta.1

정식 0.1.13과 같은 기능을 담은 첫 별도 개발판입니다. 새로운 기능을 먼저 시험할 개발판 업데이트 경로를 제공합니다.

- 앱 이름에 Beta가 붙으며 정식판과 별도로 설치됩니다.
- 설정·프리셋·대기열·API 키 저장 공간이 정식판과 분리됩니다. 첫 실행은 빈 작업 공간이며 필요한 재료는 설정 백업으로 가져올 수 있습니다.
- 개발판에서 최신 버전으로 업데이트를 누르면 개발판만 확인합니다. 정식판을 선택하면 정식판 별도 설치 파일을 엽니다.
- 정식판 자료를 자동 복사하거나 덮어쓰지 않습니다. 기존 정식판은 그대로 사용할 수 있습니다.

시험판입니다. PixAI와 제휴하지 않은 비공식 도구이며 실제 생성에는 본인의 공식 API 키와 크레딧이 필요합니다.
