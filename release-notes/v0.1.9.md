# PixaiClackHelper 0.1.9

- 조합 재료를 프리셋·캐릭터·청크 탭으로 정리하고, 이미지 비율·장수·모드는 선택 요약 아래에서 접고 펼칩니다. 기본은 **이 예약만** 적용하며, 기본값 변경은 별도로 선택합니다.
- 제목줄과 메뉴를 한 줄로 줄이고 예약 합계·등록·저장 버튼을 칸 아래에 고정했습니다. 좁은 창은 2칸과 접힌 레일로 표시합니다.
- 씬을 격자/목록으로 보고, 셋째 칸에서 청크 사본·문구·이미지·그룹을 편집합니다. 복제 저장은 원래 씬을 보존합니다.
- 라이브러리에 저장 여부 표시·미저장 전환 확인·여러 항목 이동/복제/삭제·새 폴더 이동을 추가했습니다. 폴더 사이 드래그 이동도 지원합니다. 공통문은 별도 하위 탭, 출연과 사용처는 오른쪽 칸에서 봅니다.
- **예약 후 바로 등록**은 이번 구성만 대기열에 등록합니다. 실제 유료 생성은 대기열에서 시작을 확인해야 합니다.
- 대기열에 상태별 필터와 예약 묶음 표시를 추가했습니다. 칸 비율·접힌 칸·씬 보기 방식은 재시작과 앱용 백업에 유지됩니다.

기존 설정과 백업을 읽을 수 있습니다. 새 화면 설정을 읽지 못하는 구버전으로의 되돌리기를 막기 위해 데이터 형식 6 / DB 19를 사용합니다. 스크립트용 내보내기는 앱 전용 화면 설정을 제외합니다. 등록된 작업과 생성 이미지는 기존처럼 수동 설정 백업에 포함하지 않습니다.

**설정 → 업데이트 확인 → 최신 버전으로 업데이트**로 받으세요. 편집 중인 재료는 먼저 저장해 주세요.

PixAI와 제휴하지 않은 비공식 도구입니다. NAIS3 기반 GPL-3.0 소프트웨어이며 배포 시 해당 버전 소스와 라이선스를 함께 제공합니다.
