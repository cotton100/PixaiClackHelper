# PixaiClackHelper 0.1.20-beta.2

씬 탭의 추가 청크 선택을 왼쪽 캐릭터 목록 아래로 옮겼습니다.

- 왼쪽을 위아래 반씩 나눠 **캐릭터 / 추가 청크**를 함께 고릅니다. 각 목록은 따로 스크롤합니다.
- 가운데 경계를 드래그하거나 위·아래 방향키로 높이를 조절합니다. 조절한 비율은 다음 실행 때도 유지됩니다. Home 키로 반반 배치로 돌아갑니다.
- 오른쪽 **문구 순서·미리보기**에서 캐릭터·씬·추가 청크 순서와 선택한 청크끼리의 순서를 바꿉니다. 접어도 선택 요약이 표시됩니다.
- 생성 문구·예약 사본·배치 수·백업 형식은 beta.1과 같습니다. 추가 청크 선택은 모든 캐릭터×씬 조합에 함께 적용됩니다.

같은 앱과 자료를 사용하는 개발판입니다. 데이터 형식 9·DB 형식 19를 유지합니다. 데이터 형식 8 이하 버전으로의 앱 내 전환은 차단되며, 정식 Latest는 0.1.19로 유지됩니다.
