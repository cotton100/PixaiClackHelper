# 0.1.25 — 프리셋·공통문 폴더 정리와 청크 순서 수정

- 라이브러리의 모델·LoRA 프리셋과 공통문 세트를 폴더로 정리합니다. 폴더 추가는 왼쪽 목록의 추가 버튼 옆에 있으며, 이름 변경·삭제·폴더 순서 드래그를 지원합니다.
- 항목을 폴더로 끌어 옮기거나 여러 항목을 선택해 이동·복제·삭제할 수 있습니다. 기본 공통문은 별도 고정 항목으로 유지합니다. 폴더 삭제는 재료를 지우지 않고 미분류로 옮깁니다.
- 폴더·소속·순서는 앱 전체/선택 백업과 같은 PC 동기화에서 유지됩니다. 선택 백업에서 프리셋·공통문 폴더별로 범위를 고를 수 있습니다.
- 새 폴더 정보를 동기화하려면 스크립트 0.10.22 이상이 필요합니다. 구버전 상대가 폴더를 누락시키지 않도록 자료 반영 전에 업데이트 안내를 표시합니다. 스크립트에서는 폴더 정보를 보존하며 폴더 편집은 앱에서 합니다.
- 새 폴더 구조를 읽지 못하는 0.1.24 이하로 자료를 덮어쓰지 않도록 데이터 형식을 11로 올립니다. 기존 백업은 읽을 수 있으며 DB 버전은 19로 유지합니다. 이미 만든 예약·작업의 문구는 폴더 정리로 바뀌지 않습니다.
- 조합 예약의 가운데 「순서·미리보기」에서 손잡이를 빠르게 끌면 청크 순서가 바뀌지 않던 문제를 수정했습니다. 손잡이를 잡는 즉시 이동을 시작하며, 변경한 순서는 미리보기·예약·재시작 복원에 그대로 반영됩니다.
- 공통문·캐릭터가 앞에 고정되던 제한을 없앴습니다. 청크를 공통문 앞이나 캐릭터 사이에도 배치할 수 있으며 포지·네거 미리보기, 최근 조합·즐겨찾기, 예약·등록 작업, 앱 백업이 같은 순서를 보존합니다. 기존 예약의 문구는 바뀌지 않습니다.
- 씬은 청크 묶음을 저장하는 기존 방식을 유지합니다. 공통문·캐릭터 사이의 배치까지 다시 쓰려면 조합 즐겨찾기를 사용하세요. 스크립트 0.10.22도 같은 자유 순서를 지원하며, 앱용 전체/선택 백업으로 예약·조합 기록을 양방향으로 옮길 수 있습니다. 구형 스크립트용 내보내기는 보존할 수 없는 항목을 안내 후 제외합니다.
- 같은 PC 동기화는 기존처럼 재료와 폴더를 공유합니다. 예약·실행 대기열·최근/즐겨찾기·초안·API 키는 동기화하지 않으며, 동기화 중에도 기존 예약의 문구와 순서를 보존합니다.
- 스크립트의 최신 전체 백업(v2)도 바로 가져올 수 있습니다. 브라우저의 PNG 정보 기록 선택은 가져오지 않고 앱의 기록 설정을 유지합니다.
