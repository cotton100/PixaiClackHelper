# PixaiClackHelper 0.1.20

씬에서 캐릭터·장면에 추가 청크를 함께 붙이고, 합치는 순서를 직접 정할 수 있습니다.

- 씬 왼쪽을 위아래로 나눠 **캐릭터 / 추가 청크**를 함께 고릅니다. 청크는 개별 또는 폴더 단위로 선택하며 모든 캐릭터×씬 조합에 적용됩니다. 추가 청크가 조합 수를 늘리지는 않습니다.
- 두 목록은 따로 스크롤합니다. 가운데 경계를 드래그하거나 위·아래 방향키로 높이를 조절하고, Home 키로 반반 배치로 돌아갑니다. 조절한 높이는 다음 실행에도 유지됩니다.
- 오른쪽 **문구 순서·미리보기**에서 **캐릭터 / 씬 / 추가 청크** 묶음과 추가 청크끼리의 순서를 드래그로 정합니다. 접어도 선택 요약이 남고, 첫 조합의 실제 포지·네거 문구를 확인할 수 있습니다.
- 씬에도 들어 있는 청크를 추가 선택하면 중복 안내가 표시됩니다. 추가 청크와 순서는 구성 저장·앱용 백업에 보존되며, 예약 시 사본으로 고정해 이후 원본 수정·삭제로 기존 예약이 바뀌지 않습니다.
- 기존 예약의 문구와 트리거 설정을 유지합니다. 스크립트용 내보내기는 지원하지 않는 추가 청크·문구 순서가 있는 예약을 제외하고 안내합니다.

기존 앱과 같은 설치·자료 폴더를 사용하며 설정과 라이브러리를 이어 씁니다. 데이터 형식은 **9**, DB 형식은 **19**입니다. 이전 자료를 읽을 수 있지만 새 자료 보호를 위해 데이터 형식 8 이하 버전으로의 앱 내 전환은 차단됩니다.

개발판을 사용 중이라면 설정의 업데이트 수신 채널을 **정식판**으로 바꾼 뒤 업데이트를 확인하세요. 정식판 사용자는 기존 업데이트 버튼으로 받을 수 있습니다.
