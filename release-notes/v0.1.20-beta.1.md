# PixaiClackHelper 0.1.20-beta.1

씬에서 선택한 캐릭터와 장면에 추가 청크를 함께 붙이고, 문구 묶음 순서를 바꿀 수 있습니다.

- 씬 오른쪽의 **추가 청크·문구 순서**에서 청크를 개별 또는 폴더 단위로 선택합니다. 모든 캐릭터×씬 조합에 적용되며 작업 수는 늘어나지 않습니다.
- **캐릭터 / 씬 / 추가 청크**의 손잡이를 드래그해 순서를 정합니다. 추가 청크끼리도 순서를 바꿀 수 있고, 접어도 선택 요약이 보입니다.
- **첫 조합 문구 미리보기**에서 실제 포지·네거 문구를 확인합니다. 씬에도 들어 있는 청크를 추가 선택하면 중복 안내가 표시됩니다.
- 추가 청크와 순서는 구성 저장·앱용 백업에 보존됩니다. 예약할 때 사본으로 고정하므로 이후 원본 수정·삭제나 앱 재시작으로 예약 문구가 바뀌지 않습니다.
- 기존 예약의 문구와 트리거 설정은 유지됩니다. 스크립트용 내보내기에서는 지원하지 않는 추가 청크·문구 순서가 있는 예약을 제외하고 안내합니다.

개발판을 선택한 사용자에게 제공하는 시험 버전입니다. 정식판과 같은 앱·자료 폴더를 사용하며 별도 설치가 아닙니다. 데이터 형식은 **9**, DB 형식은 **19**입니다. 이전 자료를 읽을 수 있지만 새 자료를 보호하기 위해 데이터 형식 8 이하 버전으로의 앱 내 전환은 차단됩니다. 정식판은 0.1.19로 유지됩니다.
